## ✨ Hitos Logrados

1. **Decisión de herramienta con criterio de experto (skills)** — Se evaluó TestSprite ("sprite7" del usuario = TestSprite, agente QA con IA vía MCP), Cypress, Playwright, Midscene y agentes IA de navegador. Veredicto: **Playwright como backbone**, por tres hechos de ESTE repo: (a) la CSP de `proxy.ts` con `nonce` + `strict-dynamic` rompe la inyección de scripts de Cypress (Playwright maneja el navegador por protocolo externo, no inyecta nada); (b) Next 16.1.6 + React 19.2.4 son bleeding-edge (Cypress tarda en soportarlos; Playwright es agnóstico del framework); (c) datos sensibles NSGC: TestSprite corre en sandbox cloud (egreso de datos, créditos) vs Playwright 100% local. TestSprite queda como auditoría IA puntual opcional; agentes IA como Midscene descartados para suite durable (no deterministas).

2. **Infraestructura (`playwright.config.ts`)** — `webServer` automático (levanta `next dev` y lo apaga), Chrome del sistema vía `channel: "chrome"` (cero descargas de navegadores), `trace: on-first-retry`, `screenshot/video` on-failure, timeouts calibrados a compilación fría de turbopack. Patrón de proyecto `setup`: login real UNA vez → `storageState` (`e2e/.auth/admin.json`, gitignored) compartido por todos los proyectos dependientes.

3. **Specs E2E (`e2e/`)** — `auth/ingresar.spec.ts`: credenciales inválidas → alerta "Credenciales inválidas.", login exitoso → `/admin`, y sin sesión `/admin` → redirect `/ingresar` (proxy verificado en navegador real, no solo curl). `smoke/modulos.spec.ts`: 8 rutas (`/admin`, `/comunidad/personas`, `/comunidad/comunicacion`, `/finanzas/gastos-comunes`, `/inventario/recursos`, `/operaciones/reservas`, `/personas/personal`, `/visor-mensajes`) renderizan su `main` y con **0 excepciones JS no capturadas** (`pageerror`). `auth/rate-limit.spec.ts`: flujo de bloqueo 10/15min completo pero **gateado** con `E2E_RATE_LIMIT=1` (contamina el contador persistente por IP de SG D-v; correr solo en CI aislado).

4. **Ejecución verde** — **12 passed / 1 skipped** (el gated, por diseño), ~2.3 min con servidor tibio. `tsc --noEmit` 0 errores. Suite Vitest 413/413 intacta. Lane separation estricta según skill `react-testing`: Vitest = lógica con mocks, Playwright = flujos de usuario completos; cero duplicación.

5. **Aprendizajes técnicos del proceso (quirúrgicos)** —
   - El route announcer de Next (`#__next-route-announcer__`) expone `role="alert"` y provoca **strict mode violation** con `getByRole("alert")` → scoping al `form` (`page.locator("form").getByRole("alert")`).
   - La **compilación fría** de turbopack hace que el primer POST de login tarde ~7s (ruta API + RSC por compilar) → `expect.timeout` 15s y `testTimeout` 120s en local (30s en CI con build de producción).
   - El navegador no lanza video si falta el `ffmpeg` de Playwright (`npx playwright install ffmpeg`, 2.3MB).
   - `/admin` aterriza en `/admin/gestion` (hereda el fix P8) — el smoke lo valida de paso.
   - El login real con `admin@test.cl` / password TEST funciona contra `prisma/dev.db` sembrada por `seed:authz`.
