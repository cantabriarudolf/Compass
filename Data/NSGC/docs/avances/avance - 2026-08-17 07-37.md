# Avance de Desarrollo - 17 de Agosto de 2026

## 📋 Resumen: Hidratación SSR segura en páginas del store, normalización de Fase 0 y correcciones en EF

En este día se trabajó en dos frentes. Primero se corrigió un error de hidratación de React (hydration mismatch) en `/inventario/estructura`, se aplicó el patrón skeleton + `hasHydrated` a todas las páginas que consumen el store y se ancló la regla en el spec ST, el documento NSGC de ST y el comando `/valida-datos`. También se formalizó el módulo RG en OpenSpec y se normalizó el tracking de Fase 0 del dashboard de desarrollo. Más tarde se desarchivó el módulo EF para corregir la creación de unidades huérfanas, mejorar la distinción entre etiquetas de Maestros Administrativos y sectores reales de Estructura Física, y hacer más visible la creación de Sub-Sectores.

Verificado vía curl: todas las rutas devuelven el skeleton en SSR.
2. **Regla permanente en spec ST**: nuevo requirement "Hidratación segura en renderizado SSR" en `openspec/specs/ST-capa-datos-persistente/spec.md` (validado con `openspec validate`).
3. **Documento NSGC actualizado**: nueva sección 6 "Hidratación y Renderizado SSR" en `ST - Capa de Datos Persistente.md`, con la regla obligatoria para páginas nuevas (`useStoreRehydrated()` + guard `hasHydrated` + skeleton).
4. **Comando `/valida-datos` actualizado**: el punto 3 ahora exige el patrón skeleton/guard para que los módulos futuros lo cumplan antes de cerrar el change.
5. **RG formalizado en OpenSpec**: nuevo spec `openspec/specs/RG-reglas-generales/` (7 requirements derivados de `RG - Reglas Generales.md`) y change archivado `2026-08-17-RG-reglas-generales` (validados con CLI).

7. **EF desarchivado y corregido**:
   - El change `EF-estructura-fisica` se movió de `openspec/changes/archive/` a `openspec/changes/` y se marcó como 🔵 En Proceso en trazabilidad.
   - Se corrigió el bug que permitía crear unidades sin Macro-Sector ni Micro-Sector; ahora el formulario exige ambos y valida antes de guardar.
   - Se mejoró la distinción entre etiquetas de Maestros Administrativos y sectores reales de Estructura Física.
