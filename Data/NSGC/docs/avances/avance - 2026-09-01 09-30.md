## 📋 Resumen: ABAC contextual puro `puedeContextual` behavior-preserving + migración GD
Se ejecuta P4 de SERIE-FRONTERA (C4.1 rp-abac-contextual). Se formaliza el ABAC que hoy estaba hardcodeado inline como modelo puro en `lib/authz.ts`: `ContextoABAC { personaId, unidadId, unidadIdsVinculadas, privacidad }` y `puedeContextual(rol, accion, recurso, ctx) = puede() base + refinamiento` solo para recursos granulares (`:propios`, `:propia`, `:residencia`, `:al_dia`, privacidad). `administrador` bypassa refinamientos. Resto delega directo a `puede()`. STRICTAMENTE behavior-preserving: si un test existente fallara, la migración estaría mal.
