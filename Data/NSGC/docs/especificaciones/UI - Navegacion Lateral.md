# UI - Navegación Lateral

Este módulo define la estructura y comportamiento del menú de navegación lateral de la aplicación.

## 1. Navegación Categorizada

El menú de navegación sigue la jerarquía definida en la documentación del proyecto. Al abrir el Sidebar, el usuario ve las siguientes categorías:

- Panel de Control
- Gestión de Comunidad
- Finanzas y Operación
- Infraestructura y Activos
- Reportes y Auditoría
- Configuración

## 2. Resaltado de Ruta Activa

La ruta activa se resalta visualmente en el menú:

- Al estar en `/dashboard`, el ítem "Inicio" se resalta.
- Al navegar a otras rutas, el ítem correspondiente a la ruta actual se resalta.
